# Mocks v2: image-led

Seven static pages generated by `build.py` from the app's own data (`public/data/`) and the credited pictures in
`public/images/` (73 pictures, all listed in `public/images/credits.json`). Shared styles are in `v2.css`; the
candidate-report graphics come from `charts.py`.

```
cd web
python3 docs/polish/mocks-v2/build.py /path/to/eso0932a-large.jpg   # the 6000 × 3000 ESO file, for the event's "where is it" crop
python3 -m http.server 8000                                          # then open /docs/polish/mocks-v2/home.html
```

The build also regenerates the derived pictures it needs: `public/images/sky/where/<event>.jpg` (the compact-sky crop)
and `public/images/data/wasp18-tess-pixels-s0104.png` (WASP-18's TESS pixels). It records each in `credits.json`.
Constellation lines, names and boundaries are in `data/`, from d3-celestial (BSD-3-Clause, `data/LICENSE-d3-celestial.txt`).

**How words were counted:** every visible text node on the full page, nav included. Closed drawers, **i** popovers
and SVG chart or map labels are excluded; the SVG labels are given as +n. The counts for today's app and for v1 are
in DIRECTION.md.

**About the captures:**
- They are full-page. Sticky elements are set to static for the capture only.
- The 390 captures are 375 wide because Chromium draws a 15px scrollbar.
- On `/sky` at 390 the panorama is a strip you pan sideways; the capture shows its start.

**Not mocked:**
- open **i** popovers and open drawers (both work in the HTML);
- the post-vote state;
- loading and error states;
- the 3D sky itself (MAPUI).
